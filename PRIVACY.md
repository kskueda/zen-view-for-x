# Privacy Policy for Zen View for X

Effective date: July 22, 2026

Zen View for X is designed to work entirely inside your browser.

## Data collection

Zen View for X does not collect, retain, sell, or transmit personal information, browsing history, communications, authentication information, financial information, or website content.

## Local processing

The extension reads the structure and visible labels of pages on `x.com` and `twitter.com` only to hide or restyle the interface elements selected by the user. This processing happens locally and page content is not retained.

## Local storage

The extension stores only visibility preferences through `chrome.storage.local`. These preferences remain in the browser profile and are not sent to the developer or any third party.

## Permissions

- `storage`: saves the user's visibility preferences locally.
- Access to `x.com` and `twitter.com`: applies the selected interface changes on those sites.

## Remote services and analytics

Zen View for X contains no analytics, advertising SDKs, tracking, remotely hosted code, or network service operated by the developer.

## Changes

Material changes to this policy will be documented in this repository and reflected in the policy's effective date.

## Contact

Questions can be opened through the repository's [GitHub issues](https://github.com/kskueda/zen-view-for-x/issues).

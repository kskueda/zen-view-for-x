# Chrome Web Store Privacy Answers

## Single purpose

Zen View for X gives users local controls to hide or compact distracting interface elements on X.

## Permission justification

### storage

Stores only the user's visibility preferences locally in the browser so the selected interface remains consistent between visits.

### Host access to x.com and twitter.com

Required to inspect and restyle X interface elements selected by the user. Page content is processed locally and is not retained or transmitted.

## Remote code

No. All executable code is included in the extension package.

## Data use

The extension does not collect or transmit user data. It locally processes website content only to apply the user's selected display changes.

## Certifications

- The extension's use of information is limited to its single stated purpose.
- Data is not sold or transferred to third parties.
- Data is not used for advertising, creditworthiness, lending, or unrelated purposes.
- The extension does not use analytics, tracking, or developer-operated remote services.

## Distribution

- Visibility: Public
- Countries: All available countries
- In-app purchases: No

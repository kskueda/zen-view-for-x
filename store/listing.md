# Chrome Web Store Listing

## Name

Zen View for X

## Summary

A calmer X experience with controls for metrics, promoted posts, sidebars, and compact navigation.

## Detailed description

Zen View for X turns X into a calmer, cleaner reading space while keeping the timeline and normal post interactions usable.

Choose exactly what remains visible:

- Reply, repost, like, and view counts
- Promoted posts
- Premium subscription prompts
- Live broadcast modules
- Recommended-user modules
- Trends and news modules
- Text labels in the left navigation

When every right-rail module is hidden, Zen View also removes the remaining search box, dividers, placeholders, and footer links. Compact navigation reduces the large Post button to a small pencil control and keeps the timeline aligned beside it.

Settings are available from both the extension popup and a compact control on X. Preferences are stored locally in the browser.

Privacy first:

- No analytics or tracking
- No remote scripts
- No developer-operated servers
- No collection or transmission of page content
- Only display preferences are stored locally

Zen View for X currently provides a Japanese settings interface. It works on `x.com` and `twitter.com` in Chromium-based browsers, including Arc and Chrome.

Zen View for X is an independent project and is not affiliated with, endorsed by, or sponsored by X Corp.
